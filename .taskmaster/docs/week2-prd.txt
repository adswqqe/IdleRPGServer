# Week 2: Idle Game Loop & Progression System

## 프로젝트 개요
IdleRPG 서버의 핵심 방치형 게임 시스템 구현. 플레이어가 로그아웃해도 게임이 진행되고, 로그인 시 보상을 받을 수 있는 시스템을 개발합니다.

## 목표
- 자동 전투 시스템 구현
- 오프라인 보상 계산 로직 개발
- Background Service를 이용한 서버 사이드 진행 처리
- 전투 로그 및 기록 시스템 구축

---

## Feature 1: Monster Entity 및 Repository

### 요구사항
- Monster 엔티티 생성 (Domain Layer)
- MonsterRepository 구현 (Infrastructure Layer)
- 기본 몬스터 데이터 시딩

### 상세 스펙
**Monster Entity 필드:**
- Id (Guid, PK)
- Name (string) - 몬스터 이름
- Level (int) - 몬스터 레벨
- MaxHealth (int) - 최대 체력
- Attack (int) - 공격력
- Defense (int) - 방어력
- ExperienceReward (int) - 처치 시 경험치
- GoldReward (int) - 처치 시 골드
- CreatedAt, UpdatedAt (DateTime)

**Repository 메서드:**
- GetByIdAsync(Guid id)
- GetByLevelRangeAsync(int minLevel, int maxLevel)
- GetAllAsync()
- CreateAsync(Monster monster)

**데이터베이스:**
- EF Core 마이그레이션 생성
- 초기 몬스터 5종 시딩 (레벨 1, 5, 10, 15, 20)

## Feature 2: Battle System - Core Logic

### 요구사항
- 전투 로직 구현 (Application Layer)
- BattleService 생성
- 전투 결과 DTO 정의

### 상세 스펙
**BattleService 메서드:**
- `SimulateBattleAsync(Guid characterId, Guid monsterId)`
  - 캐릭터와 몬스터의 스탯 비교
  - 전투 시뮬레이션 실행
  - 승패 결정 및 보상 계산
  - 캐릭터 경험치/골드 업데이트
  - 전투 로그 저장

**전투 공식:**
```
공격자 데미지 = Max(1, 공격력 - 방어자 방어력)
턴제 전투 (공격 속도 고려 안함)
HP가 먼저 0이 되는 쪽이 패배
```

**BattleResultDto:**
- IsVictory (bool)
- ExperienceGained (int)
- GoldGained (int)
- DamageDealt (int)
- DamageTaken (int)
- TurnsCount (int)

## Feature 3: Battle Controller & API

### 요구사항
- BattleController 생성 (API Layer)
- 전투 시작 API
- 전투 상태 조회 API

### 상세 스펙
**API Endpoints:**

1. `POST /api/battle/start`
   - Request: `{ "characterId": "guid", "monsterId": "guid" }`
   - Response: BattleResultDto
   - 인증: Required ([Authorize])

2. `GET /api/battle/random-monster?level={level}`
   - 캐릭터 레벨 기준 적절한 몬스터 랜덤 선택
   - 레벨 ±2 범위 내 몬스터
   - Response: MonsterDto

## Feature 5: Offline Reward System

### 요구사항
- 오프라인 보상 계산 서비스
- OfflineRewardService 구현
- RewardController API

### 상세 스펙
**OfflineRewardService 메서드:**
- `CalculateOfflineRewardsAsync(Guid characterId)`
  - 현재 시간 - LastLoginTime 계산
  - 최대 8시간까지만 인정
  - 분당 획득량 계산 (캐릭터 레벨 기반)
  - 보상 DTO 반환 (실제 지급은 안함)

- `ClaimOfflineRewardsAsync(Guid characterId)`
  - 보상 계산
  - 캐릭터에 경험치/골드 적용
  - LastLoginTime 업데이트

**보상 공식:**
```
분당 경험치 = 캐릭터 레벨 * 2
분당 골드 = 캐릭터 레벨 * 1
최대 누적 시간 = 8시간 (480분)
```

**OfflineRewardDto:**
- MinutesOffline (int)
- ExperienceEarned (int)
- GoldEarned (int)
- LevelsGained (int)

**API Endpoints:**

1. `GET /api/rewards/offline/{characterId}`
   - 오프라인 보상 계산 (조회만)
   - Response: OfflineRewardDto

2. `POST /api/rewards/offline/{characterId}/claim`
   - 오프라인 보상 수령
   - Response: OfflineRewardDto + 업데이트된 Character 정보

## Feature 6: Idle Progress Background Service

### 요구사항
- IHostedService 구현
- 주기적으로 활성 캐릭터들의 진행 처리
- IdleProgressService 생성

### 상세 스펙
**IdleProgressService:**
- BackgroundService 상속
- 매 1분마다 실행
- 마지막 로그인 시간이 현재 시간과 가까운 캐릭터들 조회
  - 예: 최근 1시간 이내 로그인한 캐릭터
- 각 캐릭터마다 자동 전투 시뮬레이션
  - 캐릭터 레벨 기준 랜덤 몬스터 선택
  - 전투 시뮬레이션 실행
  - 결과 저장

**구현 기술:**
- IHostedService / BackgroundService
- PeriodicTimer 사용
- CancellationToken 처리
- 에러 핸들링 및 로깅

**Program.cs 등록:**
```csharp
builder.Services.AddHostedService<IdleProgressService>();
```
