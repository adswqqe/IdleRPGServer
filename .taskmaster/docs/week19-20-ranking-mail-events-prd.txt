### 기술 요구사항

**Redis Sorted Set 활용**:
```csharp
public class RankingService {
    private readonly IConnectionMultiplexer _redis;

    // 랭킹 업데이트
    public async Task UpdateLevelRanking(int userId, int level) {
        var db = _redis.GetDatabase();
        await db.SortedSetAddAsync("ranking:level", userId, level);
    }

    public async Task UpdatePvPRanking(int userId, int mmr) {
        var db = _redis.GetDatabase();
        await db.SortedSetAddAsync("ranking:pvp", userId, mmr);
    }

    public async Task UpdateGuildRanking(int guildId, int guildLevel) {
        var db = _redis.GetDatabase();
        await db.SortedSetAddAsync("ranking:guild", guildId, guildLevel);
    }

    // 랭킹 조회 (상위 100명)
    public async Task<List<RankingEntry>> GetTopLevelRanking(int count = 100) {
        var db = _redis.GetDatabase();
        var entries = await db.SortedSetRangeByRankWithScoresAsync(
            "ranking:level",
            0,
            count - 1,
            Order.Descending
        );

        return entries.Select((e, index) => new RankingEntry {
            Rank = index + 1,
            UserId = (int)e.Element,
            Score = (int)e.Score
        }).ToList();
    }

    // 내 순위 조회
    public async Task<int?> GetMyRank(int userId, string rankingType) {
        var db = _redis.GetDatabase();
        var rank = await db.SortedSetRankAsync($"ranking:{rankingType}", userId, Order.Descending);
        return rank.HasValue ? (int)rank.Value + 1 : null;
    }

    // 내 주변 순위 조회 (±10명)
    public async Task<List<RankingEntry>> GetRankingsAroundMe(int userId, string rankingType) {
        var db = _redis.GetDatabase();
        var myRank = await db.SortedSetRankAsync($"ranking:{rankingType}", userId, Order.Descending);

        if (!myRank.HasValue) return new List<RankingEntry>();

        long start = Math.Max(0, myRank.Value - 10);
        long end = myRank.Value + 10;

        var entries = await db.SortedSetRangeByRankWithScoresAsync(
            $"ranking:{rankingType}",
            start,
            end,
            Order.Descending
        );

        return entries.Select((e, index) => new RankingEntry {
            Rank = (int)start + index + 1,
            UserId = (int)e.Element,
            Score = (int)e.Score
        }).ToList();
    }
}
```

- ArenaService에서 MMR 변화 시 랭킹 업데이트

**Background Service (랭킹 갱신)**:
```csharp
public class RankingUpdateService : BackgroundService {
    protected override async Task ExecuteAsync(CancellationToken stoppingToken) {
        while (!stoppingToken.IsCancellationRequested) {
            await Task.Delay(TimeSpan.FromMinutes(10), stoppingToken);

            // 전체 캐릭터 레벨 랭킹 갱신 (10분마다)
            var characters = await _context.Characters
                .OrderByDescending(c => c.Level)
                .Take(1000)
                .ToListAsync();

            foreach (var character in characters) {
                await _rankingService.UpdateLevelRanking(character.Id, character.Level);
            }
        }
    }
}
```

## Feature 21: Mail & Event System (Week 20)

### 게임 메커니즘
- 시스템 메일 (운영자 발송)
- 보상 메일 (이벤트, 보상)
- 친구 선물 메일
- 유효 기간 (7일/30일)
- 기간 한정 이벤트

### 기술 요구사항

**엔티티 설계**:
- Mail 엔티티
  - Id, UserId (FK)
  - Type (System, Reward, Gift)
  - Subject, Body
  - IsRead, IsClaimed
  - SentAt, ExpireAt
  - SenderName (선택 사항)

- MailAttachment 엔티티
  - Id, MailId (FK)
  - Type (Gold, Diamond, Item, Pet)
  - ItemId or PetId (FK, nullable)
  - Quantity

- Event 엔티티
  - Id, Name, Description
  - Type (ExpBoost, GoldBoost, GachaDiscount)
  - BonusPercentage (보너스 %)
  - StartDate, EndDate
  - IsActive

**Configuration**:
- MailConfiguration
  - 인덱스: UserId, SentAt, ExpireAt

- EventConfiguration
  - 인덱스: IsActive, StartDate, EndDate

**서비스 로직**:
- MailService
  - GetMailList(userId, page, size): 우편 목록
  - GetMailDetails(mailId): 우편 상세
  - ClaimAttachment(mailId): 보상 수령
  - DeleteMail(mailId): 우편 삭제
  - ClaimAll(userId): 일괄 수령
  - DeleteAll(userId): 일괄 삭제
  - SendSystemMail(userIds[], subject, body, attachments[]): 시스템 메일 발송 (Admin)

- EventService
  - GetActiveEvents(): 진행 중 이벤트 목록
  - GetEventDetails(eventId): 이벤트 상세
  - ParticipateEvent(userId, eventId): 이벤트 참여
  - GetEventRanking(eventId): 이벤트 랭킹

**시스템 메일 발송 예시**:
```csharp
// 전체 사용자에게 보상 메일 발송
public async Task SendRewardToAll(string subject, string body, List<MailAttachment> attachments) {
    var allUsers = await _context.Players.Select(p => p.Id).ToListAsync();

    foreach (var userId in allUsers) {
        var mail = new Mail {
            UserId = userId,
            Type = MailType.Reward,
            Subject = subject,
            Body = body,
            SentAt = DateTime.Now,
            ExpireAt = DateTime.Now.AddDays(7),
            Attachments = attachments
        };

        _context.Mails.Add(mail);
    }

    await _context.SaveChangesAsync();
}
```

**이벤트 보너스 적용**:
```csharp
// BattleService에서 경험치 계산 시
public int CalculateExpWithBonus(int baseExp) {
    var activeEvents = _eventService.GetActiveEvents()
        .Where(e => e.Type == EventType.ExpBoost);

    float bonusMultiplier = 1.0f;
    foreach (var evt in activeEvents) {
        bonusMultiplier += evt.BonusPercentage;
    }

    return (int)(baseExp * bonusMultiplier);
}
```

**Background Service (만료 우편 삭제)**:
```csharp
public class MailCleanupService : BackgroundService {
    protected override async Task ExecuteAsync(CancellationToken stoppingToken) {
        while (!stoppingToken.IsCancellationRequested) {
            await Task.Delay(TimeSpan.FromHours(24), stoppingToken);

            // 만료된 우편 삭제
            var expiredMails = await _context.Mails
                .Where(m => m.ExpireAt < DateTime.Now && m.IsClaimed)
                .ToListAsync();

            _context.Mails.RemoveRange(expiredMails);
            await _context.SaveChangesAsync();
        }
    }
}
```
