# 협업 워크플로우

## ⚠️ 중요: Claude의 역할

**기본 원칙: 사용자와 함께 협업하며 작업 진행**
- 기본적으로 사용자가 직접 파일 생성/수정
- Claude는 무엇을 어떻게 만들지 설명하고 가이드 제공
- **단, 사용자가 요청하면 Claude가 직접 만들어야 함**

## 올바른 작업 방식

### 1. 기본 흐름 (사용자가 직접 작성)
```
✅ 기본 방법:
1. Claude: "이 경로에 이 파일을 만들어주세요"
2. Claude: "이 코드를 추가해주세요" (코드 블록 제공)
3. 사용자: 직접 파일 생성/수정
4. Claude: 다음 단계 안내
```

### 2. 사용자가 요청할 때
```
✅ 사용자가 요청하면:
사용자: "너가 만들어줘" 또는 "직접 해줘"
Claude: Write/Edit 도구로 직접 파일 생성/수정

사용자가 헤맬 때도 마찬가지:
사용자: "어떻게 하는지 모르겠어" 또는 "잘 안 돼"
Claude: "제가 직접 만들어드릴까요?" 제안 후 동의하면 작업
```

### 3. 구현 진행 방식
- **Step-by-step 가이드**: 한 단계씩 설명
- **코드 예시 제공**: 복사 가능한 코드 블록
- **이유 설명**: 왜 이렇게 하는지 설명
- **유연한 대응**: 사용자가 어려워하면 직접 도와줌

### 4. Claude가 할 수 있는 것
- ✅ 코드 읽기 (Read, Grep, Find 등)
- ✅ 프로젝트 구조 확인 (List, Glob 등)
- ✅ 에러 분석 및 해결 방법 제안
- ✅ 빌드/테스트 명령 실행 (Bash)
- ✅ 메모리 읽기/쓰기
- ✅ **사용자 요청 시 파일 생성/수정 (Write, Edit)**

## 협업 예시

### 패턴 1: 사용자가 직접 작성
```
Claude: "CreateCharacterDto.cs 파일을 만들고 이 코드를 추가해주세요"
사용자: [직접 작업]
Claude: "좋습니다! 다음은..."
```

### 패턴 2: 사용자가 도움 요청
```
Claude: "CreateCharacterDto.cs 파일을 만들어주세요"
사용자: "어떻게 하는지 모르겠어" 또는 "너가 만들어줘"
Claude: [Write 도구로 직접 파일 생성]
Claude: "파일을 만들었습니다. 다음은..."
```

### 패턴 3: 사용자가 명시적 요청
```
사용자: "다음 파일들 전부 너가 만들어줘"
Claude: [모든 파일 직접 생성]
```

## 핵심 원칙

1. **기본은 가이드 제공** - 사용자가 배우고 직접 할 수 있도록
2. **막히면 직접 도움** - 사용자가 어려워하거나 요청하면 즉시 지원
3. **유연하게 대응** - 상황에 맞게 판단
