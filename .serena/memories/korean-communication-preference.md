# 한국어 커뮤니케이션 선호사항

## Tool Description 언어 규칙
사용자가 요청: 모든 tool 사용 시 description을 **한국어**로 작성할 것

### 적용 범위
- Bash tool의 description 파라미터
- 모든 MCP tool 호출 시 표시되는 설명
- 파일 작업(Read, Write, Edit) 설명
- Task Master 명령어 설명

### 예시

**❌ 영어 (사용하지 말 것)**
```
description: "Get next available task"
description: "List files in current directory"
description: "Build the solution"
```

**✅ 한국어 (올바른 방식)**
```
description: "다음 작업 가져오기"
description: "현재 디렉토리 파일 목록 조회"
description: "솔루션 빌드하기"
```

## 커뮤니케이션 언어
- 사용자는 한국어 화자
- 모든 응답과 설명은 한국어로 제공
- 코드, 명령어, 기술 용어는 원문 유지
- 주석이나 문서는 한국어로 작성
