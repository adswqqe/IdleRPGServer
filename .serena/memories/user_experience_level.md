## 지원 방식 조정 필요
웹서버 개발 초보자이므로 다음과 같이 접근:

### 1. 설명 방식
- **단계별 상세 설명**: 각 단계마다 왜 필요한지 설명
- **Unity와 비교**: Unity 개념과 연관지어 설명
- **코드 주석**: 코드의 각 부분이 하는 역할 상세 설명

### 2. 학습 순서
- **기초부터 차근차근**: 복잡한 기능보다는 기본기 먼저
- **하나씩 완성**: 한 번에 여러 기능보다는 하나씩 완전히 구현
- **테스트 중심**: 각 단계마다 동작 확인

### 3. 실습 위주
- **실제 코드 작성**: 이론보다는 직접 코딩해보며 학습
- **에러 해결**: 발생할 수 있는 오류와 해결 방법 미리 안내
- **디버깅 방법**: 문제 발생 시 어떻게 찾아서 해결하는지

## Unity 개발자 관점에서 웹서버 개념 매핑

### Unity → 웹서버 개념 비교
- **GameObject** → **Controller** (요청 처리)
- **Component** → **Service** (기능 구현)
- **ScriptableObject** → **DTO** (데이터 전송)
- **PlayerPrefs** → **Database** (데이터 저장)
- **Event System** → **SignalR** (실시간 통신)
- **Scene** → **API Endpoint** (화면/기능 단위)

## 권장 학습 경로
1. **기본 API 하나 완성**: 간단한 GET/POST 요청
2. **데이터베이스 연동**: Entity Framework 기초
3. **인증 시스템 이해**: JWT 토큰 개념
4. **실시간 통신**: SignalR 기본 개념
5. **고급 기능**: 채팅, 복잡한 게임 로직
