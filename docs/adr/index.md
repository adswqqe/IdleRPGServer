## 📚 사용법

### 새 ADR 작성
1. 번호 발급: 마지막 ADR 번호 + 1
2. 파일명: `ADR-XXXX-kebab-case-title.md`
3. [TEMPLATE.md](./TEMPLATE.md) 복사하여 작성
4. 500단어 이내로 간결하게 작성
5. 이 index.md에 항목 추가

### ADR 상태
- **Proposed**: 제안 중
- **Accepted**: 승인됨 (프로덕션 적용)
- **Rejected**: 기각됨
- **Deprecated**: 더 이상 사용하지 않음
- **Superseded**: 다른 ADR로 대체됨
