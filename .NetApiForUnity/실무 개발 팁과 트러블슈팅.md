## 🚨 자주 하는 실수들

### 1. N+1 쿼리 문제
```csharp
// ❌ 잘못된 방법 (N+1 문제)
var players = await context.Players.ToListAsync();
foreach(var player in players) {
    var characters = await context.Characters
        .Where(c => c.PlayerId == player.Id).ToListAsync();
}

// ✅ 올바른 방법
var players = await context.Players
    .Include(p => p.Characters)
    .ToListAsync();
```

### 2. 메모리 누수
```csharp
// ❌ 잘못된 방법 (Change Tracking 누적)
public class GameService {
    private readonly GameDbContext _context; // 장기간 유지
}

// ✅ 올바른 방법 (적절한 생명주기)
public class GameService {
    private readonly IDbContextFactory<GameDbContext> _factory;
    
    public async Task DoSomething() {
        using var context = await _factory.CreateDbContextAsync();
        // 작업 후 자동 해제
    }
}
```

### 3. 비동기 패턴 실수
```csharp
// ❌ 데드락 위험
var result = SomeAsyncMethod().Result;

// ✅ 올바른 비동기 패턴
var result = await SomeAsyncMethod();
```

## 🔧 성능 최적화 팁

### Entity Framework
- `AsNoTracking()` 읽기 전용 쿼리에 사용
- `Split Query` 다중 Include 시 사용
- `Compiled Query` 반복 실행 쿼리에 사용

### 데이터베이스
- 적절한 인덱스 생성
- Connection Pooling 설정
- 쿼리 실행 계획 분석

### Unity 통합
- 토큰 자동 갱신 구현
- 네트워크 재연결 로직
- 에러 처리 및 사용자 피드백
