# Project Brief

## Overview

**방치형 RPG 서버** 는 Unity 게임 기반의 모바일 RPG 게임을 위한 RESTful API 서버입니다. Clean Architecture 원칙을 바탕으로 ASP.NET Core 8.0으로 개발되었으며, 다음과 같은 특징을 가집니다:

- **방치형 결입**: 플레이어가 오프라인 상태에서도 캐릭터 성장
- **대규모 확장성**: 많은 동시 사용자 지원
- **리얼타임 업데이트**: 게임 상태 동기화
- **안정성과 성능**: 서버 최적화 및 보안

## Core Requirements

### 기본 기능 요구사항
- **사용자 인증 및 인가**: JWT 기반 보안 시스템
- **캐릭터 관리**: 생성, 조회, 수정, 삭제 (CRUD)
- **인벤토리 시스템**: 아이템 관리 및 거래
- **스탯 시스템**: 캐릭터 능력치 관리
- **오프라인 리워드**: 비활성 시간 보상

### 기술적 요구사항
- **Clean Architecture**: 레이어 분리 및 의존성 역전
- **CQRS 패턴**: 명령과 조회 분리
- **Repository 패턴**: 데이터 액세스 추상화
- **PostgreSQL**: 관계형 데이터베이스
- **Redis**: 대기 상태 (캐싱 및 세션 관리)
- **Docker**: 컨테이너화 및 배포

### 성능 요구사항
- **응답 시간**: 95% 요청 100ms 이하
- **동시 사용자**: 10,000+ 사용자 지원
- **가용성**: 99.9% 업타임
- **자동 스케일링**: 수평 확장 지원

## Goals

### 단기 목표 (1-3개월)
- **MVP 개발 완료**: 기본 캐릭터 및 인벤토리 시스템
- **인증 시스템**: JWT 기반 로그인/회원가입
- **API 문서화**: Swagger를 통한 완전한 API 문서
- **기본 게임 로직**: 캐릭터 생성, 레벨업, 아이템 획득

### 중기 목표 (3-6개월)
- **오프라인 시스템**: 비활성 시간 동안 진행되는 사냥 및 보상
- **리얼타임 기능**: SignalR를 이용한 실시간 업데이트
- **성능 최적화**: 캐싱, 데이터베이스 인덱싱, 쿼리 최적화
- **모니터링**: 로깅, 메트릭, 성능 추적

### 장기 목표 (6개월+)
- **대규모 서비스**: 수만 명 동시 사용자 지원
- **고가용성**: 로드 밸런싱, 장애 조치, 백업/복구
- **글로벌 서비스**: 멀티 리전 서뺄스 및 CDN
- **애널리틱스**: 플레이어 행동 분석 및 게임 밸런싱

## Success Metrics

### 기술적 메트릭
- **API 응답 시간**: 평균 < 100ms
- **에러율**: < 0.1%
- **업타임**: > 99.9%
- **코드 커버리지**: > 80%

### 비즈니스 메트릭
- **사용자 유지율**: 월간 > 70%
- **일일 활성 사용자**: 지속적 증가
- **세션 길이**: 평균 > 30분
- **서버 비용**: 사용자당 비용 최소화

## Target Audience

### 주 타겏 사용자
- **연령대**: 18-35세
- **게임 경험**: RPG 및 전략 게임 선호
- **플레이 스타일**: 캐주얼 또는 세미 코어 게이머
- **기기**: 모바일 디바이스 (iOS/Android)

### 비즈니스 모델
- **Freemium**: 기본 게임 무료, 프리미엄 기능 유료
- **In-App Purchase**: 게임 내 가상화폐 및 아이템 판매
- **광고 수익**: 리워드 기반 광고
- **배틀패스**: 시즌 기반 콘텐츠 제공
