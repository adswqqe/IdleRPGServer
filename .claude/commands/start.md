# Start Command - 프로젝트 시작 자동화

이 명령어는 새 세션 시작 시 필요한 모든 초기화 작업을 수행합니다.

## 작업 순서

1. **Serena 프로젝트 활성화**
   - `serena` 프로젝트 활성화

2. **주요 메모리 읽기**
   - `development_roadmap_checklist` - 8주 학습 로드맵
   - `tech_stack` - 기술 스택 우선순위
   - `4-checkpoint-api-status-current` - 현재 API 구현 상태
   - 가장 최근 checkpoint 메모리 (4-checkpoint-week* 형태)

3. **현재 상태 요약**
   - 완료된 작업
   - 진행 중인 작업
   - 다음 우선순위

4. **사용자에게 물어보기**
   - "어떤 작업을 진행할까요?"
   - 옵션 제시 (이전 작업 계속 / 새 작업 시작 / 학습 주제 선택)

이제 다음 작업을 계속 진행해주세요.
