# 2025-10-23 SDD 워크플로우 개선 논의

## 📌 논의 배경

### 현재 상황
- **Pet System** 구현을 위한 SDD(Spec-Driven Development) 문서 작성
  - requirements.md: 254줄
  - design.md: 1,256줄 (구체적인 코드 50줄 포함)
  - tasks.md: 559줄
  - **총 2,069줄** (구현 예상 시간 18.5시간 대비 30-38% 오버헤드)

### 핵심 문제
1. **AI가 "복사 기계"로 전락**: 문서의 코드를 그대로 복사-붙여넣기
2. **과도한 문서 유지보수**: 작은 수정에도 모든 문서 업데이트 필요
3. **학습 기회 상실**: 구현이 이미 결정되어 있어 학습자가 고민할 기회 없음

## 🤖 AI 모델들의 분석

### 1. Claude (독립 분석)
- **위험**: 일관성 붕괴, AI 모델 의존성, 디버깅 블랙박스, 학습 곡선 역전
- **제안**: "첫 구현 상세, 이후 원칙" 전략

### 2. GPT-5 Pro
- **10가지 위험 요소 식별**:
  - 일관성/재현성 붕괴
  - 디버깅/추적 가능성 하락
  - 온보딩 난이도 상승
  - 아키텍처 침식
- **해결책**: 최소 가드레일 세트 (표준 가이드 1-2페이지, 스캐폴드 고정, ADR-lite)

### 3. Gemini 2.5 Pro
- **교육학적 관점**: "왜"에 대한 학습 부재, 엔지니어링 '감각' 형성 불가
- **제안**: **Progressive Scaffolding** (점진적 스캐폴딩)
  - Phase 1: Concrete-First (구체적 예시)
  - Phase 2: Guided Collaboration (유도된 협업)
  - Phase 3: Autonomous Collaboration (자율 협업)

### 4. Grok-3
- **핵심 통찰**: **"과잉 엔지니어링 자체가 문제"**
- **제안**: 복잡한 문서 대신 **페어 프로그래밍**
- **장점**: 실시간 피드백, 구체적 학습, 적응성

## 🎯 최종 제안: Progressive Context System

### 1. Minimal Context File (최소 컨텍스트)
**`.claude/current-work.md`** (100줄 이하)
```markdown
# Current Work Context

## 🎯 현재 작업: 펫 시스템 구현
**진행률**: 3/7 단계 완료
**마지막 작업**: 2024-01-15 - PetTemplate Entity 생성

## 📝 주요 결정사항
- Entity 메서드 vs Domain Service → Entity 메서드 선택

## ⚠️ 미해결 이슈
- [ ] 트랜잭션 범위 결정 필요

## 🔄 다음 단계
1. CharacterPet Repository 구현

## 💭 학습 필요 개념
- 트랜잭션 (Transaction)
- Unit of Work 패턴
```

### 2. Proactive Concept Detection (개념 선제 감지)
- AI가 코드 분석하여 "학습자가 곧 만날 개념" 미리 설명
- "모르는 것을 모르는" 문제 해결
- Just-In-Time 학습

### 3. Smart Work Log (스마트 작업 로그)
**`.claude/work-log.jsonl`** (자동 생성)
```json
{"date": "2024-01-15", "action": "create", "target": "PetTemplate.cs"}
{"date": "2024-01-15", "action": "learn", "concept": "Transaction"}
```

## ✅ 개선 효과

### Before (SDD 방식)
```
문서 (2,069줄) → AI (복사) → 학습자 (구경)
```

### After (Progressive Context)
```
학습자 질문 → AI 제안 → 학습자 선택 →
AI 구현 지원 → 학습자 리뷰 → 반복
```

### 주요 개선점
1. **문서 부담**: 2,069줄 → 100줄 (95% 감소)
2. **AI 역할**: 복사 기계 → 사고하는 파트너
3. **학습 효과**: 수동적 구경 → 능동적 의사결정
4. **세션 연속성**: 100줄 컨텍스트로 즉시 복원

## 🎓 핵심 교훈

> "문서가 아니라 대화가 답이다"

- 문서화는 학습의 도구일 뿐, 목적이 되어서는 안 됨
- AI는 타이핑 머신이 아니라 사고하는 파트너여야 함
- 학습자는 구현 과정에서 "왜"를 이해해야 함
