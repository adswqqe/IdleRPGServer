## 💡 주요 아키텍처 원칙 (로드된 메모리 기반)

### Clean Architecture
- **API** → Application → Domain ← Infrastructure
- Domain은 독립적 (Pure Business Logic)
- Repository Pattern, Service Pattern, ValueObject Pattern (DDD)

### 서버 권위 설계
- 모든 중요 로직 서버 계산 (전투, 보상, 가챠, 강화)
- 클라이언트는 표현만 (UI, 애니메이션)
- 클라이언트 데이터 절대 신뢰 금지

### 기술 스택
- **서버**: ASP.NET Core 8.0, PostgreSQL 14, EF Core 9.0, JWT, BCrypt
- **클라이언트**: Unity 6, UniTask, Newtonsoft.Json
- **인프라**: AWS (EC2, RDS), Docker, Jenkins CI/CD
